# Auto Instrumentation vs Manual Instrumentation
###### OpenTelemetry 

| Feature              | Java Agent                                                            | Java SDK                                          | 🎯 Spring Boot OTel Starter                                                                                            |
| -------------------- | --------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Installation         | **Easy** (Just java agent)                                            | **Hard** (Setup dependencies and configuration)   | **Easy** (Just spring dependency and minor configuration)                                                           |
| Auto Instrumentation | ✅ **Yes** (zero-code changes)                                         | ❌ **No**                                          | ⚠️ **Yes** (not include all out of the box instrumentation of the Java Agent)                                       |
| Custom data          | **Limited**, needs manual instrumentation with manual instrumentation | ✅ **Yes**                                         | ✅ **Yes**                                                                                                           |
| Performance Overhead | **Higher** (Instumenting all available libraries at run time)         | **Lower** (Just the libraries you need/configure) | **Lower** (Just the libraries you need/configure)                                                                   |
| AOT / GraalVM        | ❌ **Not supported**                                                   | ✅ **Yes**                                         | ✅ **Yes**                                                                                                           |
| Maintenance          | **Easy** (Just update java agent version)                             | **Hard** (Needs ongoing upkeep)                   | **Intermediary** (Spring team will deal with most of the upkeep, but you still to keep tracking as the app evolves) |
